Music Website – Frontend Web Development

A responsive music streaming website developed as part of my Frontend Web Development Internship at CodeAlpha. This project was created to practice and demonstrate my skills in HTML, CSS, and JavaScript by building a modern music-player interface inspired by popular music streaming platforms.

Features
🎵 Modern and responsive music player interface
▶️ Play and pause music functionality
⏭️ Music navigation and playback controls
📊 Interactive music progress bar
🔍 Search bar and navigation interface
🎨 Custom UI design with CSS
📱 Responsive layout for different screen sizes
✨ Smooth hover effects and transitions
🖥️ Multiple pages with consistent design
